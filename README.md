# iv mediz Admin Panel

React + TypeScript + Vite admin UI aligned with the Flutter mobile app.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173

Demo login is prefilled: `admin@ivmediz.app` / `admin123`

## Screens

- Dashboard
- Jobs
- Applications
- Professionals
- Hospitals
- Ambulances
- Notifications
- Settings
